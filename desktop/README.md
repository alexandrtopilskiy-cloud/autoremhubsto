# Офлайн-кабинет AutoRemHub СТО

Установщик `AutoRemHub-Setup-x64.exe` собран для Windows x64. Выберите папку установки и отдельную папку данных на локальном диске. Установщик создаёт ярлык и запоминает путь к данным при обновлении. При удалении программы папка данных сохраняется.

1. Войдите на сайт под аккаунтом владельца, назначенного мастером офлайн-резерва. Откройте «Резервный ПК».
2. Откройте установленную программу под тем же пользователем Windows. На стартовой странице нажмите «Настроить офлайн-кабинет». Если компьютер ещё не привязан, сначала введите код привязки с сайта.
3. Получите код загрузки снимка, введите его и задайте локальный пароль. После загрузки войдите с email владельца и заданным паролем.
4. Проверьте список заказ-нарядов. Отключите интернет, откройте существующий черновик, измените его, создайте новый наряд. Закройте и снова откройте приложение, затем проверьте оба документа.

В окне Windows используются экраны веб-кабинета и отдельная база PostgreSQL. Создание и редактирование заказ-нарядов меняют локальную базу. В этом выпуске синхронизация локальных изменений с сервером ещё не реализована. Снимок загружается при первичной настройке пустой базы. Для уже привязанного ПК установщик использует существующий ключ из профиля пользователя Windows.

Windows-сборку и артефакт установщика публикует процесс Windows offline cabinet в GitHub Actions. Для первой загрузки снимка сервер должен поддерживать передачу идентификатора назначенного мастера в desktop-replica.
