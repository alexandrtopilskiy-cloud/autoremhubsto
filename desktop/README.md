# Офлайн-кабинет AutoRemHub СТО

Установщик `AutoRemHub-Setup-x64.exe` собран для Windows x64. Выберите папку установки и отдельную папку данных на локальном диске. Установщик создаёт ярлык и запоминает путь к данным при обновлении. При удалении программы папка данных сохраняется.

1. Войдите на сайт под аккаунтом владельца, назначенного мастером офлайн-резерва. Откройте «Резервный ПК».
2. Откройте установленную программу под тем же пользователем Windows. На стартовой странице нажмите «Настроить офлайн-кабинет». Если компьютер ещё не привязан, сначала введите код привязки с сайта.
3. Получите код загрузки снимка, введите его и задайте локальный пароль. После загрузки войдите с email владельца и заданным паролем.
4. Дождитесь статуса «Онлайн · синхронизация завершена» в меню «Режим работы». Откройте облачный кабинет из Программы. Для него используется обычный вход на сайт.
5. Отключите интернет на резервном ПК, оставив Программу запущенной. Через 45 секунд после последнего запроса сервер закрывает запись для всей СТО. Резервный ПК включает локальную запись после контрольной паузы. Войдите с локальным паролем, измените черновик и создайте новый наряд.
6. Верните интернет. Программа применит локальные изменения к базе сервера, сверит итоговую копию и подтвердит открытие записи для СТО. Проверьте оба документа из браузера.

Автоматический резерв активируется после первого успешного подключения Программы. Если её закрыть, запись на сервере тоже приостанавливается. При конфликте одной записи или ограничений базы обе версии сохраняются, а режим просмотра остаётся включённым. Подробность доступна в меню «Режим работы → Состояние синхронизации». Настройки пользователей и ролей ведутся на сервере. При обновлении уже настроенного ПК используется существующий ключ привязки. Если прежняя локальная база отличается от сервера, она сохраняется и резерв не активируется до сверки данных.

После проверки сборки из main процесс Windows offline cabinet публикует установщик для ссылки на странице входа и в разделе «Резервный ПК».
