# План интеграции с Rossko

## 1. Цель и границы интеграции

Цель: Автоматизировать перенос заказов, оформленных на сайте Rossko, в систему `AutoRemHubSto` в виде приходных накладных с последующим списанием запчастей в заказ-наряды.

Что входит в интеграцию:

- [x] Настройка: Ввод и безопасное хранение ключей API.
- [x] Проверка подключения: Тестовый запрос к API Rossko.
- [x] Получение заказов: Запрос списка заказов из Rossko.
- [ ] Формирование прихода: Создание черновика приходной накладной (Receipt) на основе выбранного заказа Rossko.
- [ ] Связывание: Связывание строк прихода с номенклатурой AutoRemHubSto (по артикулу и бренду).
- [ ] Использование в ЗН: Выбор товаров из проведенной приходной накладной в заказ-наряд.
